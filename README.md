# Skywings_Airline_booking_system
This project demonstrates core Object-Oriented Programming concepts in C++ including function overloading and operator overloading. The library manages flight information, seat booking, cancellation, and automatic seat allocation across Economy, Business, and First class categories. The system simulates real-world airline operations — from searching available flights to confirming reservations — all within an intuitive graphical interface. Sky Wings successfully demonstrates a fully functional airline reservation system using Java Swing with a clean MVC structure.
